# 99Chat 运营后台 — 菜单结构

> 产品后台工程：`admin-console/`（Vue 3）  
> 旧工程 `admin/`（pure-admin）保留为遗留，不再作为产品菜单源。

## 导航规则

- 严格两级：一级业务域 → 二级页面
- 详情页不进侧栏（用户详情、群详情、隐私页从列表/详情进入）

## 菜单树

```
工作台
  └── 总览

用户
  ├── 用户列表
  ├── 账号生成任务
  └── 登录记录

社交与风控
  ├── 好友关系
  ├── 群组列表
  ├── 群动态
  ├── 消息审计
  ├── 聊天投诉
  └── 设备终端

资金
  ├── 提现审核
  ├── 账变记录
  ├── 充值记录
  ├── 转账记录
  ├── 红包记录
  ├── 闪兑记录
  ├── 链上钱包
  ├── 归集记录
  ├── 缴费订单
  ├── 缴费任务
  ├── 缴费工人
  ├── 缴费供应商
  ├── 币种管理
  ├── 闪兑配置
  ├── 手续费配置
  └── 限额配置

运营
  ├── 发送公告
  ├── 公告记录
  ├── 公众号
  ├── 用户反馈
  ├── 版本发布
  ├── 启动图
  ├── 支付助手通知
  └── 系统好友补全

系统
  ├── 平台配置
  ├── 操作审计
  ├── 管理员登录
  ├── 个人设置
  └── 高级运维
```

## 路由前缀（admin-console）

| 域 | 示例 path |
|----|-----------|
| 工作台 | `/dashboard` |
| 用户 | `/users`、`/users/:userUid` |
| 风控 | `/risk/*` |
| 资金 | `/wallet/*` |
| 运营 | `/ops/*` |
| 系统 | `/system/*` |

API 统一：`/api/v1/**`（JWT + `admin_account.permissions`）。
